AI editing

AI-assisted editing is planned. The current editor does not include an Ask AI panel or model configuration. Opening a deck does not call a model.

The planned workflow lets you request a change, review the proposed Markdown and CSS, then choose whether to apply it. A fresh isolated preview will test proposals. Applying a proposal will pause rendering until you select Render.

Do not put API keys in a deck, stylesheet or shared URL. Anyone with a shared link can read its document text.
