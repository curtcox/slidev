# Slidev Online

Write and present Slidev decks in your browser. Your deck contains Markdown in `slides.md` and optional styles in `style.css`.

## Start a deck

1. Open the [editor](../) or choose a deck from the [gallery](../gallery.html).
2. Edit the Markdown or CSS. The preview updates after a short pause.
3. Use the arrow buttons to move through slides and click reveals.
4. Select **Present** to open the preview in fullscreen, if your browser supports it. Select **Presenter** (under **More** on phones) to open a second presenter window with current and next slide previews, text speaker notes and a timer.

On phones, switch between **Slides**, **Markdown** and **CSS**. Desktop also offers **Split** view with a draggable divider. **Overview** lists the visible slides. Tap or swipe inside the preview to move through slides and click reveals. Speaker notes appear as text below the preview.

## Keep your work

**Share** creates a link with the current Markdown and CSS. **Download** (or **Print / PDF**, under **More** on phones) offers Markdown, CSS, a ZIP archive with both files, a JSON document that preserves extension fields, or printable standalone HTML with optional speaker notes.

The browser keeps a draft on this device. To recover earlier work, choose **More → Resume saved work**. Recovered drafts and imported files wait for **Render**. An explicit link always opens its own document instead of a stored draft.

You can install Slidev Online as a web app for offline use. Use **More → Repair offline copy** to reverify cached assets and **More → Apply update** to activate a waiting release without losing edits. See [supported features and offline use](supported.md).

If a slide fails to compile, the editor shows its file and source location when available. Correct the source, then select **Render**.
