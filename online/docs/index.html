Slidev Online

Write and present Slidev decks in your browser. Your deck contains Markdown in slides.md and optional styles in style.css.

Start a deck

  1. Open the editor or choose a deck from the gallery.
  2. Edit the Markdown or CSS. The preview updates after a short pause.
  3. Use the arrow buttons to move through slides and click reveals.
  4. Select Present to open the preview in fullscreen, if your browser supports it.

On phones, switch between Slides, Markdown and CSS. Desktop also offers Split view with a divider. Overview lists the visible slides. Tap or swipe inside the preview to move through slides and click reveals. Speaker notes appear as text below the preview.

Keep your work

Share creates a link with the current Markdown and CSS. Download offers Markdown, CSS, a ZIP archive with both files, or a JSON document. The JSON document also preserves extension fields.

The browser keeps a draft on this device. To recover earlier work, choose More, then Resume saved work. Recovered drafts and imported files wait for Render. An explicit link always opens its own document instead of a stored draft.

If a slide fails to compile, the editor shows its file and source location when available. Correct the source, then select Render.
